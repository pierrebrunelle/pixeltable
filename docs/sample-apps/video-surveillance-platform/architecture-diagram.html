Stage 1 — Video Upload & Base Table
POST /api/videos/upload → pxt.insert → triggers everything
INPUT ▶
📁
surveillance.videos TABLE
Base table — stores raw pxt.Video + metadata columns: site_name, camera_id, location, asset_id, gps_lat, gps_lon, tags, recorded_at, uuid (auto uuid7)
One insert triggers ALL downstream computed columns & views automatically
⏱
duration local
Video length in seconds
pixeltable.functions.video.get_duration
📋
metadata local
Container metadata: codec, resolution, fps, etc.
pixeltable.functions.video.get_metadata
🤖
Stage 2 — Video-Level Analysis
Computed columns on the videos table itself
1 API call ▶
📝
video_summary gemini
Sends the entire video to Gemini 2.5 Flash with VIDEO_SUMMARY_PROMPT. Returns structured assessment: equipment condition, worker safety, environmental hazards, security, overall risk.
gemini.generate_content([videos.video, PROMPT], model='gemini-2.5-flash')
🎬
scene_cuts local
Content-based scene boundary detection — identifies visual transition points in the video
videos.video.scene_detect_content() · PySceneDetect
🎵
audio local
Extract MP3 audio track from video (used as input for audio_chunks view below)
video.extract_audio(videos.video, format='mp3')
videos.video → 3 iterator views (auto-populated on insert)
🖼
video_frames
frame_iterator @ 1 fps
▶
🔲
frame_thumbnail local
Base64 320×320 JPEG thumbnail for UI display
pxt_image.b64_encode(thumbnail(frame))
🔍
detr_seg local GPU
DETR panoptic segmentation — object labels, bounding masks, confidence scores
huggingface.detr_for_segmentation(frame, 'facebook/detr-resnet-50-panoptic')
🎨
segmentation_overlay_b64 local
Colorized segmentation overlay with contours, 480px thumbnail, base64-encoded
vision.overlay_segmentation → thumbnail → b64_encode
🧲
embedding index gemini
Multimodal image embedding — enables text ↔ image ↔ video cross-modal search
gemini.embed_content('gemini-embedding-2-preview')
🎞
video_segments
video_splitter 10s / 2s overlap
▶
📊
segment_analysis gemini ×1
The master Gemini call. Sends 10s video clip + SEGMENT_ANALYSIS_PROMPT. Returns JSON: { description, severity, severity_reason,
  ppe_status, ppe_details,
  equipment[], hazards[] }
gemini.generate_content([video_segment, SEGMENT_ANALYSIS_PROMPT])
🧲
embedding index gemini
Multimodal video embedding — enables video ↔ text ↔ audio cross-modal search
gemini.embed_content('gemini-embedding-2-preview')
🔊
audio pipeline
split → transcribe → sentences
▶
✂
audio_chunks iterator
30-second audio segments via audio_splitter
audio.audio_splitter(audio=videos.audio, duration=30)
💬
transcription local
Whisper speech-to-text, runs locally
whisper.transcribe(model='base.en')
📖
video_sentences iterator
Split transcripts into sentences (filtered: transcription != None)
string.string_splitter(separators='sentence')
🧲
embedding index gemini
Text embedding for transcript similarity search
gemini.embed_content('gemini-embedding-2-preview')

Stage 4 — FastAPI REST Layer
4 routers · pure reads — all AI runs in Pixeltable computed columns
API ▶
POST
/api/videos/upload
Upload file → pxt.insert → triggers all computed columns
POST
/api/search
Text query → .similarity() on segments + frames + transcripts
POST
/api/search/by-image
Image → matching frames + segments (cross-modal)
POST
/api/search/by-video
Video clip → matching segments + frames
GET
/api/browse/segments
Segment clips + parsed JSON analysis (severity, PPE, equipment, hazards)
GET
/api/browse/detections
DETR segmentation overlays from video_frames
GET
/api/dashboard/stats
Severity counts from segments, DETR labels, ROI metrics
GET
/api/dashboard/alerts
Segments where severity = CRITICAL or WARNING

Provider & Cost Legend
Gemini generate_content (API — ~5 calls/video) Gemini embed_content (API — ~49 calls/video) DETR / Whisper / PySceneDetect (local — $0) Pixeltable built-in functions (local — image/video/string ops)
Pixeltable Schema — surveillance.*
videos TABLE
video, site_name, camera_id, location, asset_id, gps_*, tags, uuid, timestamp, duration, metadata, video_summary, scene_cuts, audio
video_frames VIEW
frame, pos, frame_thumbnail, detr_seg, segmentation_overlay_b64 + embedding index
video_segments VIEW
video_segment, segment_start, segment_end, segment_analysis + embedding index
audio_chunks VIEW → video_sentences VIEW
audio_segment, transcription.text → sentences + embedding index
